Ejercicio · ¿Esto es gestión de datos?

Seis situaciones de un proyecto. Hay que señalar todas las que sean decisiones de gestión de datos según lo visto en esta unidad didáctica.

>>Señalar todas las situaciones que constituyen una decisión de gestión de datos.<<

[x] Acordar que el identificador de sujeto será un código correlativo y que la tabla que lo relaciona con la historia clínica la custodia la coordinadora del estudio
[ ] Decidir el tamaño muestral del estudio a partir de la potencia estadística
[x] Escribir en el consentimiento que los datos podrán reutilizarse en investigaciones posteriores relacionadas
[x] Anotar por qué se excluyeron catorce casos durante la limpieza de la base de datos
[ ] Elegir la revista a la que se enviará el artículo
[x] Comprobar con el servicio de informática si la carpeta del grupo tiene copias de seguridad

[explanation]
Son decisiones de gestión de datos la primera, la tercera, la cuarta y la sexta. La prueba es siempre la misma: si la decisión responde a alguna de las cinco preguntas —qué datos, dónde, cómo se entienden, cuánto tiempo, con quién—, es una decisión de gestión de datos.

**El identificador y la custodia de la tabla de correspondencia** es «cómo se codifican los sujetos», uno de los ejemplos que se daban de decisión que no se puede revisar al terminar. Hasta dónde llegan sus consecuencias se verá en el bloque C.

**Lo que dice el consentimiento** sobre la reutilización responde a «con quién»: fija el techo de todo lo que se podrá compartir después. Es el *dato incompartible*, y no hay forma de arreglarlo más tarde.

**Documentar las exclusiones** responde a «cómo se entienden». Sin ese registro los datos siguen ahí, pero el resultado no se puede reconstruir: es el *dato no reproducible*.

**Preguntar por las copias de seguridad** —en vez de suponerlas— responde a «dónde», y es lo que separa un conjunto de datos del *dato irrecuperable*.

No lo son el **tamaño muestral**, que es una decisión de diseño del estudio, ni la **elección de revista**, que es una decisión de difusión. Las dos son importantes, y ninguna responde a ninguna de las cinco preguntas.
[explanation]

Preguntas de repaso

>>¿Cuál de estos elementos NO se considera dato de investigación?<<
( ) El diccionario que explica el significado de cada variable
( ) El código de análisis que produce las tablas del artículo
(x) La memoria científica presentada a la convocatoria
( ) Las imágenes de resonancia de los sujetos incluidos
[explanation]
La memoria es un **documento** del proyecto, no un dato de investigación. El diccionario, el código y las imágenes sí lo son: sin ellos no se puede comprobar ni reproducir un resultado.
[explanation]

>>¿Cuándo se toman las decisiones de gestión de datos de un proyecto?<<
( ) Al terminar el proyecto, cuando ya se sabe qué datos hay
( ) Cuando la revista pide depositar los datos
(x) Antes de empezar a recoger datos, porque condicionan lo que se podrá hacer después
( ) Solo si el financiador exige un plan de gestión de datos
[explanation]
Decisiones como el consentimiento, la codificación de los sujetos o el formato de recogida **determinan lo que será posible más adelante** y no se pueden revisar al final. Se toman igual aunque nadie exija un documento.
[explanation]

>>Un fichero con datos completos que nadie sabe interpretar porque no existe documentación, ¿qué problema ilustra?<<
(x) El dato huérfano
( ) El dato irrecuperable
( ) El dato incompartible
( ) El dato no reproducible
[explanation]
Es el **dato huérfano**: existe, se puede abrir, y no sirve porque se perdió el significado. Irrecuperable sería si el soporte hubiera desaparecido; incompartible, si existiera un impedimento legal.
[explanation]

>>¿Qué distingue a un instituto de investigación sanitaria en cuanto a gestión de datos?<<
( ) Que sus datos siempre son anónimos
(x) Que buena parte de sus datos se generaron con finalidad asistencial y pertenecen al hospital
( ) Que no necesita autorización de comités para usar datos clínicos
( ) Que sus repositorios admiten siempre acceso abierto
[explanation]
El rasgo distintivo es la **convivencia con la actividad asistencial**: el dato de historia clínica es del hospital, se generó para tratar pacientes y el proyecto lo usa con autorización. De ahí que existan comités de acceso y unidades que centralizan las extracciones.
[explanation]

>>En investigación biomédica, «datos accesibles» según la ciencia abierta significa habitualmente que…<<
( ) Cualquiera puede descargar los datos de los pacientes
(x) Los datos están descritos y son obtenibles por quien tenga un motivo legítimo y autorización
( ) Los datos se publican una vez pasados cinco años
( ) Los datos se envían por correo a quien los solicite
[explanation]
La fórmula es *tan abierto como sea posible, tan cerrado como sea necesario*. Con datos de salud, lo habitual es **describir el conjunto públicamente** y dar acceso al dato mediante solicitud autorizada, no publicarlo para descarga libre.
[explanation]
