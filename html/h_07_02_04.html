( ) Porque lo exige el calendario de las convocatorias
(x) Porque es el único momento en que las decisiones todavía se pueden tomar, y no solo describir
( ) Porque después el equipo no tiene tiempo de escribirlo
( ) Porque el comité de ética lo requiere antes del dictamen
[explanation]
El presupuesto se pide antes de la concesión; el consentimiento se redacta antes de reclutar; la codificación se estandariza al definir el cuaderno.

Mantener el documento después no es corregir un pronóstico fallido: es **registrar las decisiones a medida que se toman**.

>>De las tres versiones que suele tener un plan, dos las reclama un trámite y una no la reclama nadie. ¿Cuál es la que ningún trámite obliga a producir?<<
( ) La de la solicitud
(x) La de puesta en marcha, en los primeros meses del proyecto
( ) La de cierre
( ) Ninguna: las tres se entregan al financiador
[explanation]
La de la **solicitud** la pide la convocatoria y la de **cierre** la pide la justificación de la ayuda. La de **puesta en marcha** no la reclama nadie, y es justamente la que de verdad guía el proyecto: se escribe cuando ya se sabe qué sistema se usa, qué autorizó el comité y quién hace qué.

Sin ella, la versión de la solicitud —llena de estimaciones— se queda como única referencia durante tres años.
[explanation]

>>¿Cuál de estas situaciones deja un conjunto de datos sin ficha, sin responsable, sin destino y sin plazo a la vez?<<
( ) La marcha del investigador principal
(x) La aparición de un conjunto de datos no previsto, que nunca llega a inventariarse
( ) Un cambio de repositorio
( ) La falta de presupuesto para almacenamiento
[explanation]
Alguien añade una escala, un colaborador aporta unos datos, se hace una determinación adicional. Como no estaba en el plan, ese conjunto no tiene ficha, ni responsable, ni destino, ni plazo.
[explanation]

>>¿Qué distingue un cambio que se anota en el documento de uno que hay que consultar con el comité de ética?<<
( ) Que afecte o no al presupuesto del proyecto
(x) Cambiar cómo se gestionan los datos se actualiza; cambiar qué datos se tratan o para qué se consulta
( ) Que ocurra antes o después de iniciar el reclutamiento
( ) Que implique o no a más de un centro
[explanation]
Mover los datos a otro servidor institucional o sustituir a la persona responsable son cambios de **gestión**. Ampliar las variables extraídas, incluir una población nueva o usar los datos para otro objetivo son cambios de **alcance**.

Confundirlos es caro en las dos direcciones: por exceso paraliza el proyecto; por defecto amplía el tratamiento sin cobertura.
[explanation]

>>Al actualizar el plan, ¿cuál es el paso que da valor a todos los demás?<<
( ) Subir el número de versión
( ) Comunicar el cambio al financiador
(x) Anotar en el historial qué cambió y por qué
( ) Volver a aplicar la lista de comprobación
[explanation]
Es lo que permite responder, años después, **por qué el proyecto hizo lo que hizo**. Sin esa línea, una versión nueva solo dice qué dice ahora el documento, no qué decía antes ni qué motivó el cambio.

>>Al cerrar el proyecto, ¿qué ocurre con las obligaciones sobre los datos?<<
( ) Se extinguen con la justificación de la ayuda
( ) Pasan al repositorio donde se hayan depositado
(x) Siguen vivas durante todo el plazo de conservación, y normalmente revierten a la institución
( ) Corresponden al investigador principal a título personal, de forma indefinida
[explanation]
Pueden durar diez, quince o veinticinco años, y alguien tendrá que ejecutar el borrado cuando venzan. No será quien firmó el plan.

Es la razón de fondo por la que el documento debe ser comprensible por sí mismo: será la única instrucción disponible llegado el momento.
[explanation]

>>¿Cuál es la prueba de que un plan de gestión de datos sirve?<<
( ) Que haya sido aprobado por el financiador
( ) Que cubra todos los apartados de la plantilla
(x) Que alguien ajeno al proyecto pueda decir, leyéndolo, qué hay que hacer con los datos y cuándo
( ) Que no contenga marcadores ni textos de ayuda sin sustituir
[explanation]
Es el criterio de suficiencia aplicado al documento entero.

Y tiene una ventaja práctica: si esa persona necesita preguntar algo, ahí está lo que falta por escribir — y su autor sigue disponible para escribirlo, que es una ventaja que no durará.
[explanation]
