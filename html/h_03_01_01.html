La gestión de datos se organiza por proyectos, y no es una decisión arbitraria: el proyecto es lo único que tiene a la vez las cuatro cosas que hacen falta para gestionar algo.

  • Un principio y un final definidos.
  • Un presupuesto con el que pagar lo que cueste.
  • Una persona responsable identificada.
  • Un conjunto de datos delimitado que le pertenece.

Ninguna otra unidad del instituto tiene las cuatro. Un grupo de investigación no tiene final ni presupuesto propio; una línea de investigación no tiene responsable único; un servicio no tiene datos propios.

La tensión de fondo

Aquí está el problema que ordena todo lo demás:

El proyecto termina. Los datos, no.

Un proyecto dura tres o cuatro años. Sus datos deben conservarse cinco, diez o veinticinco. El contrato de quien los manejaba dura menos que el proyecto. Y las decisiones que se tomaron al principio tienen que seguir siendo comprensibles cuando ya no quede nadie que las recuerde.

De esa asimetría salen casi todas las obligaciones que recorre este curso: documentar, nombrar responsables, fijar plazos, dejar constancia. No son burocracia: son lo que permite que los datos sobrevivan a las personas que los produjeron.

El proyecto agrupa, el conjunto decide

Conviene retener la distinción, porque es la que estructura el resto del curso:

El proyecto Es el marco: quién responde, con qué dinero, bajo qué autorizaciones, en qué plazo
El conjunto de datos Es donde se decide: dónde vive, quién accede, cuánto se conserva, qué se comparte

Un proyecto con cinco conjuntos toma cinco veces cada una de esas decisiones, y con frecuencia con resultados distintos. Tratarlas como una sola decisión de proyecto es el error que ya señalaba la unidad D2·01.

Cuando los datos cruzan proyectos

Ocurre a menudo: un proyecto nuevo quiere usar los datos de uno anterior. No es una prórroga, es un proyecto nuevo con sus propias autorizaciones. Las condiciones bajo las que se recogieron los datos originales siguen aplicándose, y se verá en el bloque siguiente que eso limita bastante más de lo que la gente supone.
